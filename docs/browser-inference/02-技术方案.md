# 浏览器端推理重构技术方案

## 2026-07-13 14:00

## 1. 总体架构

```text
摄像头/本地图片
      |
      v
Vue 主线程（预览、交互、检测框）
      |
      | ImageBitmap，单帧背压
      v
Web Worker
  - 640x640 letterbox
  - ONNX Runtime Web
  - WebGPU 优先 / WASM 回退
  - 阈值过滤与 NMS
      |
      v
Vue 主线程（本地结果）
      |
      | 每秒指标 / 确认缺陷证据 / 图片任务结果
      v
Spring Boot（业务与持久化） -> MySQL -> DeepSeek 报告
```

## 2. 模块划分

| 模块 | 职责 |
|---|---|
| `BrowserInferenceModelService` | 解析激活模型路径、计算 SHA-256、生成浏览器模型清单、提供模型文件 |
| `inference.worker.ts` | 模型初始化、预热、图像预处理、推理和后处理 |
| `BrowserInferenceClient` | Worker 生命周期、请求关联、超时和错误传播 |
| `useRealtimeStream` | 摄像头、背压调度、命中状态机、性能同步和证据提交 |
| `ImageInspectionTaskService` | 接收客户端图片结果并保存任务、文件、检测框和异常 |
| `RealtimeInspectionService` | 实时任务生命周期、指标、事件去重、证据和记录入库 |

## 3. 模型清单

`GET /api/inference/manifest`

返回模型名称、版本、下载地址、SHA-256、文件大小、输入输出名称、输入尺寸、类别顺序、阈值和建议执行后端。浏览器先下载模型并校验哈希，再创建 ONNX Runtime 会话。

`GET /api/inference/model?sha256=<hash>`

以二进制资源返回当前激活模型。哈希不匹配时拒绝下载，响应携带 ETag 与私有缓存头。

## 4. 图片质检协议

`POST /api/inspection/image/tasks/client-results`，使用 `multipart/form-data`：

- `payload`：模型哈希、备注、每张图片尺寸、推理耗时和检测框。
- `sourceFiles`：原图列表。
- `resultFiles`：前端绘制完成的结果图列表。

三个列表严格按索引对应。后端重新使用缺陷字典中的中文名和颜色，不接受客户端伪造的展示字段。

## 5. 实时质检协议

- `POST /api/inspection/realtime/start`：创建实时业务任务。
- `PUT /api/inspection/realtime/metrics`：每秒同步累计帧数、缺陷帧数、缺陷数、FPS、延迟和执行策略。
- `POST /api/inspection/realtime/client-events`：连续命中达到阈值后提交检测框及原图/结果图证据。
- `POST /api/inspection/realtime/stop`：固化统计并结束任务。

实时事件采用后端指纹和时间窗口再次去重，避免页面抖动造成重复记录。

## 6. 性能设计

- 主线程仅在上一次推理完成后创建下一张 `ImageBitmap`，不使用固定定时器堆积任务。
- Worker 内复用同一个 640x640 `OffscreenCanvas`、输入数组和推理会话。
- 模型初始化后执行一次零张量预热，首个业务帧不承担着色器编译成本。
- 视频预览直接绑定 `MediaStream`，推理帧率低于摄像头帧率时也不会影响预览流畅度。
- 仅缺陷帧生成 JPEG 证据，正常帧不编码、不上传。

## 7. 安全与部署

- 所有模型和结果接口继续使用现有 HttpOnly 会话鉴权。
- Nginx/Vite 增加 COOP、COEP 和 CORP 响应头，以启用跨源隔离和 WASM 多线程能力。
- WebGPU 与摄像头要求 HTTPS；`localhost` 仅用于本地开发。
- 客户端结果执行模型哈希、类别、置信度、坐标、文件数量和任务状态校验。

## 8. 测试策略

- 纯函数单测：坐标反变换、阈值、NMS、连续命中状态机。
- 后端集成测试：模型清单、错误哈希、图片结果入库、实时指标、实时证据和鉴权。
- 浏览器端到端：登录、真实模型加载、图片推理、结果上传；使用虚拟摄像头检查实时启动与停止。
- 构建检查：`npm run test`、`npm run build`、`mvn clean test package`、`docker compose config`。
